# Excel Lab 8 – Lookup Functions & Dynamic Reports

## 📌 Overview

This lab focuses on **retrieving and merging data** using Excel lookup functions and creating interactive reports.

## 🎯 Tasks Completed

* Retrieved Sales using `VLOOKUP`
* Retrieved Profit using `XLOOKUP`
* Retrieved City using `INDEX-MATCH`
* Merged related data using Order ID
* Created interactive **Region and Category Slicers**
* Prepared dynamic reports for dashboard analysis

## 🛠️ Skills Used

* Microsoft Excel
* VLOOKUP
* XLOOKUP
* INDEX-MATCH
* Slicers
* Data Retrieval
* Interactive Reporting
